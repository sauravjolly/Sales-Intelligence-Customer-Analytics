# Sales-Intelligence-Customer-Analytics
# Business Problem
Sales leaders needed a way to explore revenue, customer behavior, and product performance on their own, instead of waiting on manually built, backward-looking reports every time a new question came up.

# What I Did

* Wrote advanced SQL using CTEs, subqueries, aggregations, and window functions to build trend, cumulative, comparative, and year-over-year (YoY) analyses.
* Analyzed customer purchasing behavior and product-level performance to surface patterns hidden in standard reports.
* Designed an interactive Power BI dashboard with custom DAX measures and KPI cards.
* Added dynamic slicers and drill-downs so stakeholders could filter and explore the data themselves, without needing a new report built for every question.

# Tech Stack: SQL, Power BI, DAX
